# عقد السيرفر

> الحالة: مسودة مقترحة. عبدالرحمن يثبّتها مع "شكل القراءة الموحّد" يوم الجمعة.

ده كل اللي السيرفر بيعرضه. الشاشات والجهاز وخدمة الذكاء الاصطناعي بيتكلموا معاه بالطرق دي بس.

---

## القراءات

### إضافة قراءة أو أكتر

```
POST /api/readings
```

بياخد قراءة واحدة أو مصفوفة قراءات بالشكل اللي في:

```
contracts/reading.md
```

بيرجع:

```
201  القراءات اتحفظت، ومعاها لون كل واحدة
400  فيه قراءة شكلها غلط، ومعاها السبب
```

وكل قراءة بتتحفظ، السيرفر بيبعتها لايف للشاشات المفتوحة.

### جلب القراءات

```
GET /api/readings?crewId=crew-1&metric=heart_rate&from=...&to=...
```

`metric` و `from` و `to` اختياريين. بيرجع القراءات مترتبة بالوقت، وكل واحدة معاها لونها.

### الحالة دلوقتي

```
GET /api/status?crewId=crew-1
```

آخر قراءة لكل مؤشر، ولونها، والنصيحة المناسبة للونها:

```json
{
  "crewId": "crew-1",
  "overall": "yellow",
  "metrics": [
    {
      "metric": "sleep_hours",
      "value": 4.5,
      "color": "yellow",
      "takenAt": "2026-11-13T07:00:00Z",
      "advice": "...",
      "hazard": "isolation"
    }
  ]
}
```

`overall` هو أسوأ لون في كل المؤشرات.

## اللايف

```
SignalR hub:  /hubs/readings
event:        reading
```

كل قراءة جديدة بتتبعت بنفس الشكل اللي راجع من الإضافة، بلونها.

## التقارير لطبيب الأرض

### بعت تقرير

```
POST /api/reports
```

```json
{
  "crewId": "crew-1",
  "mission": "mars",
  "severity": "red",
  "summary": "...",
  "metrics": ["sleep_hours", "heart_rate"]
}
```

السيرفر بيحسب إمتى التقرير يوصل الأرض حسب مكان المهمة، ويرجّع:

```json
{
  "id": "r-12",
  "sentAt": "2026-11-13T21:00:00Z",
  "deliverAt": "2026-11-13T21:20:00Z",
  "replyEarliestAt": "2026-11-13T21:40:00Z"
}
```

### شاشة طبيب الأرض

```
GET /api/reports?crewId=crew-1
```

بيرجّع التقارير اللي وقت وصولها جه بس. اللي لسه في الطريق بيرجع بحالة:

```
in_transit
```

---

## التأخير حسب مكان المهمة

| `mission` | المكان | الرسالة بتاخد في اتجاه واحد |
|---|---|---|
| `iss` | المحطة الفضائية | ثانية تقريبًا |
| `moon` | القمر | ثانية وربع تقريبًا |
| `mars` | المريخ | من 4 لـ 20 دقيقة، والديمو بيستخدم 20 |

في الديمو فيه زرار بيسرّع الوقت، عشان الحكام مايستنوش 20 دقيقة.

---

## لغة النصايح (إضافة)

`GET /api/status?crewId=crew-1&lang=ar` بيرجّع نصايح الألوان بالعربي. من غير `lang` (أو `lang=en`) بترجع بالإنجليزي. التفاصيل في `contracts/thresholds.md`.

---

## رد طبيب الأرض (إضافة)

الرد بيعدّي نفس التأخير في الرجوع، فرحلة المريخ الكاملة 40 دقيقة.

```
POST /api/reports/{id}/reply      { "text": "..." }
GET  /api/replies?crewId=crew-1
```

- الرد مسموح بس على تقرير وصل الأرض فعلًا (لو لسه في الطريق: `409`).
- `GET /api/replies` بيرجع كل رد بحالته: `arrived` ومعاه `text`، أو `in_transit` ومعاه `secondsToDeliver` من غير النص.
- زرار "Skip to next arrival" في الديمو بيقفز لأقرب وصول، تقرير كان أو رد.

## الذكاء الاصطناعي

السيرفر هو اللي بينادي خدمة الذكاء الاصطناعي، مش الشاشات. لو الخدمة مردتش خلال 3 ثواني، السيرفر بيرجع للنتايج المحسوبة مسبقًا. التفاصيل:

```
contracts/ai.md
```
