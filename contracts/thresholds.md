# عقد حدود الألوان

> الحالة: مسودة مقترحة. ندى بتملا الأرقام في مهمة "حدود الألوان بمصادرها"، وعبدالرحمن بيقراها في مهمة "قواعد الألوان".

ندى بتكتب الحدود في ملف واحد، والسيرفر بيقراه زي ما هو. يعني لو رقم اتغيّر، بيتغيّر في الملف بس، مش في الكود.

الملف:

```
research/thresholds.json
```

---

## الشكل

لكل مؤشر: الوحدة، والمدى بتاع كل لون، والنصيحة، والخطر الفضائي، والمصدر.

```json
{
  "heart_rate": {
    "unit": "bpm",
    "bands": [
      { "color": "red",    "max": 40 },
      { "color": "yellow", "min": 40,  "max": 50 },
      { "color": "green",  "min": 50,  "max": 100 },
      { "color": "yellow", "min": 100, "max": 120 },
      { "color": "red",    "min": 120 }
    ],
    "advice": {
      "green":  "...",
      "yellow": "...",
      "red":    "..."
    },
    "hazard": "gravity",
    "sources": [
      { "title": "...", "url": "https://..." }
    ]
  }
}
```

> ⚠️ الأرقام اللي فوق مثال للشكل بس، مش أرقام حقيقية. الأرقام الحقيقية من ندى بمصادرها.

---

## قواعد

- المدى بيشمل الرقم الصغير ومبيشملش الكبير. يعني لو القيمة 100، بتاخد المدى اللي بيبدأ بـ 100.
- لو المدى ملوش حد أصغر أو أكبر، الحد ده بيتشال.
- المدايات مفيهاش فجوات، أي رقم لازم يقع في لون.
- كل مؤشر لازم يبقى ليه مصدر واحد على الأقل.
- النصيحة جملة أو اتنين، بلغة رائد الفضاء مش لغة الدكاترة.
- لكل مؤشر `advice` بالعربي المصري و`advice_en` بالإنجليزي (نفس المعنى). السيرفر بيرجّع الإنجليزي افتراضيًا (الحكام والفيديو بالإنجليزي)، والعربي بـ`?lang=ar` في `/api/status`. لو غيّرتوا نص، غيّروا الاتنين.

## الأخطار الفضائية

`hazard` لازم يكون واحد من الخمسة دول:

| `hazard` | الخطر |
|---|---|
| `radiation` | الإشعاع |
| `isolation` | العزلة والحبس |
| `distance` | البُعد عن الأرض |
| `gravity` | الجاذبية |
| `environment` | البيئة المقفولة |
