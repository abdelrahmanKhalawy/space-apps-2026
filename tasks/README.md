# فهرس المهام

كل مهمة في الشجرة ليها بريف هنا بنفس الاسم. الشجرة بتقولك إيه المتاح، والبريف بيقولك تعمله إزاي.

شجرة المهام:
```
https://abdelrahmankhalawy.github.io/task-tree/
```

## إزاي تقرا البريف

كل بريف فيه نفس الأقسام بنفس الترتيب:

1. الهدف: جملة واحدة. لو مش فاهمها، اسأل قبل ما تبدأ.
2. ليه مهمة: عشان لو اضطريت تختصر، تعرف إيه اللي ميتختصرش.
3. بتستنى إيه، وبتفتح إيه: مين قبلك ومين بعدك.
4. هتاخد إيه ومن مين: كل المدخلات بأماكنها.
5. المطلوب تعمله: الخطوات بالترتيب.
6. هتسلّم إيه وفين: الملفات بأماكنها بالظبط.
7. معايير القبول: المهمة مش خلصانة غير لما كلها تتحقق.
8. مش مطلوب منك: عشان متعملش شغل حد تاني أو شغل مرحلة جاية.
9. لو اتزنقت: الخطة البديلة، استخدمها من غير ما تستأذن.
10. لما تخلص: طلب الدمج، والشجرة، والرسالة.
