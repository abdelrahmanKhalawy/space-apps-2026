## المطلوب تعمله

1. عبدالرحمن ينشر آخر نسخة.
2. جربوا مسار العرض كامل: التلات لحظات، على اللينك المنشور، بالجهاز الحقيقي.
3. جربوه تاني والجهاز مفصول، بزرار المحاكاة.
4. جربوه تالت وخدمة الذكاء الاصطناعي مقفولة.
   ```
   git tag v2 && git push --tags
   ```
5. التيم ليد تعلّم على البوابة في الشجرة.

## معايير القبول

المهمة مش خلصانة غير لما كل دول يتحققوا. انسخهم في طلب الدمج وعلّم عليهم.

- [ ] اللحظة الأولى: صباع على الجهاز، ورقم على الشاشة في أقل من 3 ثواني.
- [ ] اللحظة التانية: السيناريو بيبيّن الانحراف واللون أخضر، ومعاه شرح فضائي.
- [ ] اللحظة التالتة: حالة حمرا، وشاشة قرار، وتقرير بيوصل لطبيب الأرض بعد التأخير.
- [ ] المسار كله شغال بالبدايل: من غير جهاز، ومن غير خدمة الذكاء الاصطناعي.
