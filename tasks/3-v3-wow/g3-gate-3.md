## المطلوب تعمله

1. عبدالرحمن ينشر آخر نسخة.
2. جربوا مسار العرض كامل بالجهاز في شكله النهائي.
3. جربوه بالبدايل تاني.
   ```
   git tag v3 && git push --tags
   ```
4. التيم ليد تعلّم على البوابة في الشجرة.
