# توقع الاتجاه

رقمها في الشجرة:

```
i4
```

- **المسؤول:** شهد أشرف
- **النوع:** مهمة
- **المسار:** الذكاء الاصطناعي
- **المرحلة:** نسخة 3: الإبهار
- **لازم تخلص قبل:** السبت 4 الفجر
- **الوقت المتوقع:** ساعتين

## الهدف

لو كمل كده، هيبقى أحمر بعد كام يوم.

## ليه مهمة

ده بيحوّل التطبيق من بيقولك حالتك لبيحميك قبل ما تتعب. أقوى جملة في اللحظة التانية من العرض.


## المطلوب تعمله

1. لكل مؤشر فيه انحراف، ارسمي خط الاتجاه من آخر كام يوم.
2. شوفي الخط هيقطع حد الأحمر إمتى.
3. رجّعي عدد الأيام ودرجة الثقة.
   ```
   POST /forecast
   ```
4. طلّعي نتايج السيناريو واحفظيها كملف جاهز.
   ```
   data/precomputed/forecast.json
   ```

## هتسلّم إيه وفين

- كود التوقع
  ```
  ai/
  ```
- النتايج الجاهزة
  ```
  data/precomputed/forecast.json
  ```

## معايير القبول

المهمة مش خلصانة غير لما كل دول يتحققوا. انسخهم في طلب الدمج وعلّم عليهم.

- [ ] التوقع للنوم في السيناريو منطقي، يعني كام يوم مش كام شهر.
- [ ] التوقع ظاهر في الداشبورد كجملة واضحة.
- [ ] لو المؤشر مش بيسوء، مفيش توقع، مش رقم غلط.
- [ ] الملف الجاهز شغال لو الخدمة وقعت.

## مش مطلوب منك

- توقع لكل المؤشرات. اللي في السيناريو كفاية.

## لو اتزنقت

- خط مستقيم بسيط كفاية. الحكام مش هيسألوا عن الطريقة قد ما هيسألوا عن الفكرة.

## تتأكد إزاي

- النتيجة تطابق اللي في البيانات التجريبية: الأحمر بييجي فعلًا بعد العدد ده.

## لما تخلص

1. افتح طلب دمج، وانسخ معايير القبول فيه.
2. بعد الدمج، علّم عليها في الشجرة.
3. ابعت للي مستنيك: الفريق كله، عشان البوابة.
