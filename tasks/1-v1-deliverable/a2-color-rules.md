# قواعد الألوان

رقمها في الشجرة:

```
a2
```

- **المسؤول:** عبدالرحمن
- **النوع:** مهمة
- **المسار:** التطبيق
- **المرحلة:** نسخة 1: تتسلم
- **لازم تخلص قبل:** الجمعة 5 العصر
- **الوقت المتوقع:** ساعة

## الهدف

كل قراءة تاخد لونها ونصيحتها من الحدود اللي ندى جمعتها.

## ليه مهمة

الألوان هي أول حاجة العين بتشوفها. ومن غير مصدر، الحكم مش هيصدقها.

## هتاخد إيه ومن مين

- ملف الحدود
  ```
  research/thresholds.json
  ```
- شكل الملف
  ```
  contracts/thresholds.md
  ```

## المطلوب تعمله

1. اقرا ملف الحدود أول ما السيرفر يشتغل.
2. لكل قراءة، دوّر على المدى اللي هي فيه، وحطله لونه.
3. رجّع اللون مع كل قراءة في الإضافة والجلب.
4. اعمل مسار الحالة: آخر قراءة لكل مؤشر، ولونها، ونصيحتها، والخطر الفضائي.
   ```
   GET /api/status
   ```
5. اللون الكلي أسوأ لون في كل المؤشرات.

## هتسلّم إيه وفين

- كود الألوان في السيرفر
  ```
  api/
  ```

## معايير القبول

المهمة مش خلصانة غير لما كل دول يتحققوا. انسخهم في طلب الدمج وعلّم عليهم.

- [ ] كل قراءة في البيانات التجريبية بتاخد لون.
- [ ] رقم على الحد بالظبط بياخد اللون الصح حسب قاعدة الملف.
- [ ] مسار الحالة بيرجّع كل المؤشرات بلونها ونصيحتها.
- [ ] لو ندى غيّرت رقم في الملف، اللون بيتغير من غير ما الكود يتغير.

## مش مطلوب منك

- الطبيعي بتاع كل رائد فضاء. ده شغل الموديل.

## لو اتزنقت

- ملف ندى لسه مجاش؟ اعمل الملف بأرقام مؤقتة مكتوب عليها مؤقت، وبدّله لما ييجي.

## تتأكد إزاي

- شهد تشوف الألوان في الداشبورد مطابقة للحدود.

## لما تخلص

1. افتح طلب دمج، وانسخ معايير القبول فيه.
2. بعد الدمج، علّم عليها في الشجرة.
3. ابعت للي مستنيك: شهد، عشان الألوان تظهر في الداشبورد.
