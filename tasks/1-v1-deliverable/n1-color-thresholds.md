# حدود الألوان بمصادرها

رقمها في الشجرة:

```
n1
```

- **المسؤول:** ندى
- **النوع:** مهمة
- **المسار:** البحث والعرض
- **المرحلة:** نسخة 1: تتسلم
- **لازم تخلص قبل:** الجمعة 5 العصر
- **الوقت المتوقع:** ساعتين ونص

## الهدف

لكل مؤشر: الأخضر والأصفر والأحمر بأرقام، ولكل رقم مصدر، ونصيحة قصيرة لكل لون.

## ليه مهمة

معيار الصحة العلمية ربع التقييم، وأول سؤال الحكم هيسأله: الأرقام دي جبتوها منين؟

## بتستنى إيه

- [قراية مصادر التحدي](../0-kickoff/k1-read-challenge-resources.md) · ندى

## بتفتح إيه

- [قواعد الألوان](a2-color-rules.md) · عبدالرحمن
- [نصوص الشرح الفضائي](../2-v2-space/n2-space-explanations.md) · ندى

## هتاخد إيه ومن مين

- الحدود اللي جمعتيها الأسبوع ده.
- شكل الملف المطلوب
  ```
  contracts/thresholds.md
  ```

## المطلوب تعمله

1. حطي الحدود اللي جمعتيها في الملف، بالشكل اللي في العقد.
2. لكل مؤشر ضيفي المصدر: اسمه ولينكه.
3. اكتبي نصيحة لكل لون: جملة أو اتنين بلغة بسيطة.
4. اربطي كل مؤشر بخطر فضائي واحد من الخمسة.
5. اتأكدي إن مفيش فجوات: أي رقم بيقع في لون.

## هتسلّم إيه وفين

- ملف الحدود اللي السيرفر هيقراه
  ```
  research/thresholds.json
  ```
- المصادر بالتفصيل
  ```
  research/sources.md
  ```

## معايير القبول

المهمة مش خلصانة غير لما كل دول يتحققوا. انسخهم في طلب الدمج وعلّم عليهم.

- [ ] كل المؤشرات اللي في النطاق موجودة.
- [ ] كل مؤشر ليه مصدر واحد على الأقل، واللينك شغال.
- [ ] مفيش فجوات ولا تداخل في المدايات.
- [ ] كل لون ليه نصيحة.
- [ ] الملف بيتقري من غير أخطاء.

## مش مطلوب منك

- نصوص الشرح الفضائي الطويلة. دي في المرحلة الجاية.

## لو اتزنقت

- مش لاقية مصدر لمؤشر؟ استخدمي مصدر طبي عام معروف للناس العادية، واكتبي ملحوظة إن الحدود في الفضاء ممكن تختلف.
- اتأخرتي؟ ابعتي أول 3 مؤشرات الأول، عشان عبدالرحمن يبدأ بيهم.

## تتأكد إزاي

- عبدالرحمن يحط الملف في السيرفر، وكل قراءة في البيانات التجريبية تاخد لون.

## لما تخلص

1. افتح طلب دمج، وانسخ معايير القبول فيه.
2. بعد الدمج، علّم عليها في الشجرة.
3. ابعت للي مستنيك: عبدالرحمن، عشان قواعد الألوان.
