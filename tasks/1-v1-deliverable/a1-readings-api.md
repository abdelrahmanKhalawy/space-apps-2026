# السيرفر وحفظ القراءات

رقمها في الشجرة:

```
a1
```

- **المسؤول:** عبدالرحمن
- **النوع:** مهمة
- **المسار:** التطبيق
- **المرحلة:** نسخة 1: تتسلم
- **لازم تخلص قبل:** الجمعة 5 العصر
- **الوقت المتوقع:** ساعة ونص

## الهدف

السيرفر بيستقبل القراءات، ويحفظها، ويرجّعها للشاشات.

## ليه مهمة

كل حاجة بعد كده بتمر من هنا: الجهاز، والفورم، والموديل، وطبيب الأرض.

## هتاخد إيه ومن مين

- عقد السيرفر
  ```
  contracts/api.md
  ```
- عقد القراءة
  ```
  contracts/reading.md
  ```
- البيانات التجريبية
  ```
  data/mock/day143.json
  ```

## المطلوب تعمله

1. اعمل جدول القراءات في قاعدة البيانات.
2. اعمل مسار الإضافة: قراءة واحدة أو مصفوفة.
   ```
   POST /api/readings
   ```
3. ارفض أي قراءة مؤشرها أو وحدتها مش في العقد، ورجّع السبب.
4. اعمل مسار الجلب بالفلاتر.
   ```
   GET /api/readings
   ```
5. حمّل البيانات التجريبية أول ما السيرفر يشتغل لو الجدول فاضي.

## هتسلّم إيه وفين

## معايير القبول

المهمة مش خلصانة غير لما كل دول يتحققوا. انسخهم في طلب الدمج وعلّم عليهم.

- [ ] إضافة قراءة صح بترجع نجاح، وبتظهر في الجلب.
- [ ] إضافة قراءة بمؤشر غلط بترجع رفض، ومعاها سبب مفهوم.
- [ ] الجلب بفلتر المؤشر والوقت شغال.
- [ ] البيانات التجريبية كلها متحملة.
- [ ] اللي فات ده شغال على اللينك المنشور، مش على جهازك بس.

## مش مطلوب منك

- الألوان. دي مهمة لوحدها.
- اللايف. ده في المرحلة الجاية.
- تسجيل دخول. مش محتاجينه خالص.

## لو اتزنقت

- قاعدة البيانات عملت مشكلة في النشر؟ احفظ في الذاكرة مؤقتًا، وكمّل. المهم الشاشات تشتغل.

## تتأكد إزاي

- شهد تبعت قراءة من الفورم وتشوفها راجعة.

## لما تخلص

1. افتح طلب دمج، وانسخ معايير القبول فيه.
2. بعد الدمج، علّم عليها في الشجرة.
3. ابعت للي مستنيك: شهد، عشان توصّل الفورم والداشبورد.
