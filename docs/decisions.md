# القرارات التقنية

أي قرار هنا اتاخد عشان محدش يضيّع وقت يوم الهاكاثون في نقاش. لو حد عايز يغيّر قرار، يتغيّر قبل الجمعة بس، وبموافقة صاحب الفولدر والتيم ليد.

كل قرار ليه حالة:

- ✅ متثبت
- 🟡 مقترح، محتاج تأكيد قبل الجمعة
- ⏳ بيتقرر في مهمة الانطلاق

---

## 1. شكل المنتج

✅ تطبيق ويب يتفتح بلينك، لأن الحكام بيجربوه من الموبايل أو اللابتوب من غير ما ينزّلوا حاجة.

✅ لينك واحد للمنتج كله. السيرفر هو اللي بيعرض الشاشات، فمفيش لينكين يتلخبطوا.

✅ شاشتين جوه نفس اللينك: شاشة رائد الفضاء، وشاشة طبيب الأرض.

---

## 2. التقنيات

### السيرفر 🟡

فريق الفول ستاك عنده خبرة دوت نت، فالسيرفر هيبقى:

```
ASP.NET Core 8 Web API
SignalR (للقراءات اللايف)
EF Core + SQLite
```

ليه قاعدة بيانات بسيطة في ملف: مفيش إعداد، ومفيش سيرفر داتابيز يقع، والداتا قليلة.

### الشاشات 🟡

```
React + Vite + TypeScript
Recharts (الرسوم)
@microsoft/signalr (اللايف)
```

لو عبدالرحمن وشهد أسرع في حاجة تانية، يغيّروها هنا قبل الجمعة. الفولدر اسمه ثابت مهما كانت التقنية.

### الذكاء الاصطناعي 🟡

```
Python 3.11
FastAPI
pandas + scikit-learn
```

خدمة اللغة اللي هتشرح السبب وترد في المساعد الطبي: ⏳ شهد أشرف ومحمد يختاروها الأسبوع ده.

### الجهاز 🟡

```
ESP32
MAX30102 (النبض والأكسجين)
حساس الحرارة اللي عمار اشتراه
Arduino IDE أو PlatformIO
```

الجهاز بيبعت القراءات للسيرفر على الواي فاي. لو الشبكة وقعت، بيبعت للابتوب على كابل، وسكريبت صغير على اللابتوب يكمّلها للسيرفر.

---

## 3. النشر ⏳

عبدالرحمن وشهد يختاروا ويعملوا الحسابات الأسبوع ده. الاقتراح:

- السيرفر والشاشات مع بعض:
  ```
  Azure App Service (Azure for Students)
  ```
- بديل لو اللي فوق اتعطل:
  ```
  Render (Docker)
  ```
- خدمة الذكاء الاصطناعي:
  ```
  Render أو Hugging Face Spaces
  ```

الشرط الوحيد: اللينك يشتغل من نافذة خاصة، ومن موبايل على شبكة تانية.
