# القرارات التقنية

كل القرارات هنا متثبتة، عشان محدش يضيّع وقت يوم الهاكاثون في نقاش. لو حد شايف قرار غلط، يقول قبل الخميس بالليل بس. بعد كده بنشتغل بيه زي ما هو.

---

## 1. شكل المنتج

- تطبيق ويب يتفتح بلينك، عشان الحكام يجربوه من الموبايل أو اللابتوب من غير ما ينزّلوا حاجة.
- لينك واحد للمنتج كله: السيرفر هو اللي بيعرض الشاشات.
- شاشتين في نفس اللينك: شاشة رائد الفضاء، وشاشة طبيب الأرض.

---

## 2. الاسم

اسم المشروع: لسه بيتحدد. التيم ليد تثبّته في مهمة "تثبيت النطاق" يوم الجمعة.

اسم الفريق:

```
Space Monkeys 🚀
```

---

## 3. السيرفر

عبدالرحمن وشهد عارفين دوت نت من تراك ديبي، فبنشتغل بيه:

```
ASP.NET Core 8 Web API
SignalR
EF Core + SQLite
```

ليه قاعدة بيانات في ملف: مفيش إعداد، ومفيش سيرفر داتابيز يقع، والداتا قليلة.

---

## 4. الشاشات

نفس اللي عبدالرحمن وشهد اشتغلوا بيه في صحتك، عشان محدش يتعلم حاجة جديدة يوم الهاكاثون:

```
React + Vite (JSX)
Recharts
@microsoft/signalr
```

الشاشات بتتبني وتتحط جوه السيرفر، فبيطلعوا مع بعض على نفس اللينك:

```
api/wwwroot
```

---

## 5. الذكاء الاصطناعي

قرار تيم الذكاء الاصطناعي: شهد أشرف ومحمد. بيكتبوه هنا قبل الخميس بالليل:

- اللغة والمكتبات: ...
- طريقة اكتشاف الانحراف: ...
- خدمة اللغة اللي بتشرح السبب وبترد في المساعد: ...
- مكان نشر الخدمة: ...

الشروط الوحيدة:

- الخدمة بترد بالأشكال اللي في عقدها:
  ```
  contracts/ai.md
  ```
- أي حاجة بتعتمد على الخدمة ليها نتايج جاهزة في فولدر البيانات، عشان الديمو يشتغل لو الخدمة وقعت.
- أي مفتاح بيتحط في إعدادات النشر، مش في الكود.

---

## 6. الجهاز

```
ESP32
MAX30102 (النبض والأكسجين)
Arduino IDE
```

وحساس الحرارة اللي عمار اختاره واشتراه.

الجهاز بيبعت للسيرفر على الواي فاي. لو الشبكة وقعت: هوت سبوت من موبايل، ولو وقع كمان: كابل للابتوب وسكريبت صغير يكمّلها للسيرفر.

---

## 7. النشر

السيرفر والشاشات مع بعض:

```
MonsterASP.NET
```

البديل لو حصلت مشكلة:

```
Azure for Students
```

مكان نشر خدمة الذكاء الاصطناعي قرار تيم الذكاء الاصطناعي، ومكتوب في قسمه فوق.

لو اللايف مشتغلش على الاستضافة لأي سبب، الشاشة بتسأل السيرفر كل ثانيتين بدله. ده مكتوب في بريف مهمة "استقبال القراءات لايف".

الشرط الوحيد: اللينك يشتغل من نافذة خاصة، ومن موبايل على شبكة تانية.

---

## 8. العقد المشترك

كل الأجزاء بتتكلم بشكل قراءة واحد:

