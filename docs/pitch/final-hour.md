# الساعة الأخيرة: بالترتيب

اتبعها بالترتيب من فوق لتحت. كل خطوة ليها صاحب، ومحدش يعلّم على خطوة غير لما يجرّبها بنفسه.
الأوامر بالإنجليزي، تتنسخ زي ما هي. القايمة دي بتكمّل `docs/submission.md` ومش بتبدّله.

> التسليم العالمي بيقفل **15 نوفمبر 11:59 م بتوقيت الحدث** حسب مصدر غير رسمي. المعاد المحلي الرسمي بيتعلن من المنظمين: تأكدوا منه قبل ما تعتمدوا على الرقم ده.

---

## 0. قبل ما تبدأ (عبدالرحمن، 5 دقايق)

- [ ] شهد قالت "فريز": مفيش كود جديد من هنا، إصلاح أخطاء بس.
- [ ] آخر `main` الـCI بتاعه أخضر على GitHub (تبويب Actions، الـ3 جوبات: web وapi وtrial).
- [ ] `docs/pitch/` متراجع من ندى وعمار (سكريبت الفيديو والسلايدز ونص الفورم).

## 1. النشر على Azure (عبدالرحمن)

الأسهل والأضمن من أي شبكة: GitHub Actions.

1. مرة واحدة بس: سر `AZURE_WEBAPP_PUBLISH_PROFILE` (الخطوات في `api/README.md`، قسم "النشر من GitHub").
2. GitHub ← **Actions** ← **Deploy to Azure** ← **Run workflow** (الفرع `main`).
3. استنى علامة خضرا. الـrun بيجرّب بنفسه الصفحة الرئيسية و`/api/health` و`/api/status` و`/api/space-weather`.

> لو الـrun أحمر: افتح الخطوة الحمرا وابعت نص الخطأ. أغلب الأسباب: السر ناقص أو Basic Auth مقفول (Settings ← Configuration ← General settings ← SCM Basic Auth Publishing Credentials).

## 2. رفع الخطة وتشغيل Always on (عبدالرحمن، اختياري ومنصوح بيه)

الخطة الحالية `F1` مجانية: بتنام بعد خمول (أول زائر يستنى 10–30 ثانية) وليها حصة CPU يومية صغيرة.

- [ ] بوابة Azure ← **App Service plan** ← **Scale up** ← **Basic B1** ← Apply.
- [ ] Web App ← **Settings ← Configuration ← General settings** ← **Always on = On** ← Save.
- [ ] راجع السعر في صفحة الخطة قبل التأكيد. بعد التحكيم ترجّعها `F1`.

## 3. مفتاح NASA (اختياري، 3 دقايق)

عشان سطر NASA DONKI (توهجات الشمس) يظهر في كارت الطقس الفضائي بدل ما يتخطّى:
- [ ] مفتاح مجاني من api.nasa.gov (بالإيميل).
- [ ] Web App ← **Settings ← Environment variables** ← اضف `Nasa__ApiKey` بقيمة المفتاح ← Save (بيعمل restart).

من غيره التطبيق بيشتغل عادي، والكارت بيعرض بيانات NOAA بس.

## 4. فحص اللينك الحي (عبدالرحمن، من شبكة بتوصل Azure)

لو الشبكة العادية بتقفل Azure، استخدم هوت سبوت الموبايل لدقيقة.

```bash
node scripts/preflight.mjs https://space-monkeys-2026.azurewebsites.net
```

**أو من GitHub (لو شبكتك بتقفل Azure):** Actions ← **Check the live site** ← Run workflow. بيصحّي التطبيق، وبيرجّع الديمو لحالته الأولى (لو سيبت خانة restore معلّمة)، وبيشغّل نفس الفحص، والنتيجة في صفحة الـrun.

- كل السطور `ok` والنتيجة `PASSED` = تمام.
- `WARN demo state is not clean` = اعمل الخطوة 5.
- `WARN space weather ... not live` = السيرفر مش بيوصل NOAA (بيعرض قراءة مسجّلة، مش مشكلة للعرض).
- `FAIL` على أي حاجة = ما نكملش، ابعت الناتج.

## 5. رجّع الديمو لحالته الأولى (أي حد)

- افتح `https://space-monkeys-2026.azurewebsites.net/#ground`.
- دوس **Restore demo data**، وبعدين شغّل الخطوة 4 تاني وتأكد إن `demo state` بقت `ok`.

> الرابط العام فيه رائد واحد وقاعدة واحدة: كل اللي بيعمله أي حكم بيشوفه اللي بعده. اعمل Restore بعد كل بروفة، وقبل ما تقدّم، وبعد ما تخلّص.

## 6. تجربة موبايل حقيقي (عمار، 10 دقايق)

دي الحاجة الوحيدة اللي مش متغطية بأي اختبار. على الموبايل اللي هتعرضوا عليه، من نافذة خاصة:

- [ ] الصفحة بتفتح من شبكة غير شبكة الفريق (بيانات الموبايل).
- [ ] **Measure my pulse with the phone camera**: اسمح بالكاميرا، إصبع على العدسة والفلاش، 25 ثانية، بيطلع نبض منطقي (قارنه بساعة أو بإيدك). جرّب مرتين. لو ما طلعش قراءة نضيفة، اتفقوا إنكم هتستخدموا **Simulate readings** وما تذكروش الكاميرا في العرض.
- [ ] **Send as my heart rate** ← الرقم بيظهر في Status وفي Body.
- [ ] ثبّت التطبيق على الشاشة الرئيسية (Add to Home screen)، وبعدين افتحه وهو في وضع الطيران: Status وReplay لازم يفتحوا.
- [ ] اضغط **No thanks** على بانر "New here?" على الجهاز ده (بيتحفظ لكل جهاز ومتصفح).
- [ ] صوت الموبايل شغّال، واضغط **Read aloud** مرة.
- [ ] البطارية فوق 50% وفيه شاحن متنقل.

## 7. لينك الفيديو والشرح (عمار وندى)

- [ ] الفيديو مرفوع ولينكه عام، واتجرّب من نافذة خاصة. (الطول المطلوب: راجعوا دليل التسليم الرسمي 2026، مش مؤكد.)
- [ ] `README.md` سطر 1: شيل تعليق الـTODO وحط لينك الفيديو تحت "Live app".
- [ ] `docs/pitch/submission-text.md`: استبدلوا `<LIVE LINK>` و`<VIDEO LINK>` و`<REPO LINK>`.
- [ ] الريبو عام (جرّب تفتحه من نافذة خاصة وأنت مش مسجّل دخول).

## 8. التسليم (عبدالرحمن)

- [ ] فورم القاهرة المحلي، ومعاه لينك الفيديو ولينك المشروع.
- [ ] الموقع العالمي، بنفس المشروع.
- [ ] صورة شاشة من التأكيد في الاتنين، في جروب الفريق.

## 9. قبل ما تدخلوا للحكام (شهد أشرف وكل الفريق)

- [ ] الخطوة 5 (Restore demo data) آخر مرة.
- [ ] افتح `/api/health` في تاب جانبي عشان السيرفر يفضل صاحي.
- [ ] تاب على **Replay** (يوم 1)، وتاب على **Evidence**، وتاب `#ground` على اللابتوب.
- [ ] بروفة الدقيقة مرتين على الأقل (`docs/pitch/video-script.md` فيه نسخة الـ60 ثانية، و`demo-checklist.md` فيه سيناريو العرض).
