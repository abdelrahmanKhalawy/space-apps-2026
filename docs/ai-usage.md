# سجل استخدام الذكاء الاصطناعي

التسليم بيطلب نقول استخدمنا الذكاء الاصطناعي في إيه. ضيف سطر كل ما تستخدمه في حاجة مهمة: كود، أو بحث، أو نص، أو صورة. سطر واحد كفاية.

عبدالرحمن بيحوّل الجدول ده لفقرة بالإنجليزي في ملف الشرح وقت التسليم.

| الوقت | مين | الأداة | استخدمها في إيه |
|---|---|---|---|
| الجمعة 10:30 | مثال | مثال | كتابة أول نسخة من ... |
| الجمعة | عبدالرحمن | Claude Code | k4: هيكل السيرفر والشاشات الفاضيين، ومسار الصحة، وخطوات النشر |
| الجمعة | عبدالرحمن | Claude Code | a1: جدول القراءات، والتحقق من العقد، ومساري POST وGET /api/readings، وتحميل البيانات التجريبية |
