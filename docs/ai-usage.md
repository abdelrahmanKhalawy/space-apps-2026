# سجل استخدام الذكاء الاصطناعي

التسليم بيطلب نقول استخدمنا الذكاء الاصطناعي في إيه. ضيف سطر كل ما تستخدمه في حاجة مهمة: كود، أو بحث، أو نص، أو صورة. سطر واحد كفاية.

عبدالرحمن بيحوّل الجدول ده لفقرة بالإنجليزي في ملف الشرح وقت التسليم.
